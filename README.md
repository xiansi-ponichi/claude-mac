# claude-mac

個人用の道具です。所有者が自分の Mac で動かす AI アシスタント（Claude Code）から、自分の Google アカウント（Gmail・Drive・Docs・Sheets）を読み書きするための OAuth クライアントです。一般向けのサービスではありません。

This is a personal, single-user tool. It lets the owner's own AI assistant (Claude Code, running on the owner's Mac) read and write the owner's own Google account (Gmail, Drive, Docs, Sheets). It is not a public service.

## プライバシー ポリシー / Privacy Policy

- 利用者は所有者本人のみです。他の人のデータは扱いません。
- Google から取得したデータは、本人の Mac の中だけで処理します。外部のサーバーに送ったり、第三者に提供・販売したりしません。
- アクセストークンは本人の Mac の中にのみ保存します。
- 本人はいつでも Google アカウントの設定からアクセスを取り消せます。

- The only user is the owner. No other person's data is processed.
- Data obtained from Google is processed only on the owner's Mac. It is never sent to external servers, shared with, or sold to third parties.
- Access tokens are stored only on the owner's Mac.
- The owner can revoke access at any time from their Google Account settings.
